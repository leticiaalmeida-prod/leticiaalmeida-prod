# Hi, I'm Leticia Almeida 👋

**Product Designer & Co-founder at GeckoVision**

I'm a product designer passionate about turning complex technical systems into clear, intuitive user experiences. At GeckoVision, I build interfaces and interaction flows for AI tools and autonomous agents.

I believe good design isn't just about how it looks, but about how the product works at the engineering level and how it solves the end user's problem. I use this GitHub to document my design decisions, interface implementations, and collaborations on real systems.

### 🛠 What I do
- **Product Design & UX/UI:** Creating user flows, high-fidelity prototypes, and usability-focused interfaces.
- **Design Systems:** Building scalable, consistent component libraries.
- **Front-end Implementation:** Hands-on knowledge of HTML, CSS, TypeScript, and animation (GSAP) to ensure a seamless handoff between design and engineering.
- **Design for AI:** Structuring interactions for bots (like `daily-news`) and autonomous agents.

### 💼 Featured Projects

*   **[My Product Design Portfolio](https://leticiaalmeida.design)** — A Next.js/TypeScript project where I not only designed but built my own portfolio, using GSAP animations and advanced responsive layouts.
*   **[GeckoVision Daily News Bot](https://github.com/leticiaalmeida-prod/daily-news)** — Collaborated on structuring the user experience and information architecture of a morning news agent on Telegram.
