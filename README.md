# Olá, sou a Leticia Almeida 👋

**Product Designer & Co-founder na GeckoVision**

Sou uma designer de produto apaixonada por transformar sistemas técnicos complexos em experiências de usuário claras e intuitivas. Na GeckoVision, construo interfaces e fluxos de interação para ferramentas de inteligência artificial e agentes autônomos.

Acredito que o bom design não é apenas sobre a aparência visual, mas sobre como o produto funciona no nível da engenharia e como ele resolve o problema do usuário final. Uso este GitHub para documentar minhas decisões de design, implementações de interface e colaborações em sistemas reais.

### 🛠 O que eu faço
- **Design de Produto & UX/UI:** Criação de fluxos de usuário, protótipos de alta fidelidade e interfaces focadas em usabilidade.
- **Sistemas de Design:** Construção de bibliotecas de componentes escaláveis e consistentes.
- **Implementação Front-end:** Conhecimento prático de HTML, CSS, TypeScript e animações (GSAP) para garantir um *handoff* perfeito entre design e engenharia.
- **Design para IA:** Estruturação de interações para *bots* (como o `daily-news`) e agentes autônomos.
