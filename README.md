## What I'm building

**[Gecko](https://geckovision.tech)** finds the facts an AI agent needs about companies,
people and tokens. Every value shows where it came from, and when a source breaks Gecko
switches to another.

I own the product side. I decide what a person sees before money moves, what a table
says when a fact is missing, and which promises the page is allowed to make. My co-founder
[Ernani](https://github.com/ernanibmurtinho) builds the engine.

## How I work

I write the rules and the exceptions before I design anything. I decide in Figma, where
a change costs minutes, and build in React with Claude Code so engineering reviews
something that behaves like the product. A clean run is not proof, so I test what the AI
produces on a sample it has not seen.
